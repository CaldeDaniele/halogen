# HALOGEN Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Browser roguelike FPS showreel (M0–M6 of the spec), with a user test checkpoint after M4.

**Architecture:** Vite + TypeScript app. Fixed-step 120 Hz Rapier simulation, interpolated Three.js rendering with a clustered forward-lighting shader injection and a pmndrs post stack. Gameplay systems talk via a typed event bus; pure logic (rng, generator, cards, damage, cluster binning, timescale) is unit tested.

**Tech Stack:** TypeScript 5 strict, Vite, three, @dimforge/rapier3d-compat, postprocessing, n8ao, vitest, playwright. Node tools for OpenRouter asset generation.

**Spec:** `docs/superpowers/specs/2026-09-27-halogen-design.md`

## Global Constraints

- Desktop KB+M only; WebGL2 + WASM required; fallback screen otherwise.
- 60 fps target at High on GTX 1660 / M1 class; tiers Low/Med/High/Ultra.
- Budgets (High): ≤40 ragdolls, ≤200 debris, ≤128 dynamic lights.
- Sim 120 Hz fixed; bullet-time scales sim dt only; mouse look never scaled.
- OpenRouter key only in `.env.local` (gitignored); hard stop at $9 total spend; runtime never calls network APIs.
- Every generated asset has a procedural fallback.
- Seeded determinism: same seed → same run graph, rooms, card offers.

## Review Focus

1. Pointer lock denied/lost mid-combat → game pauses, no stuck input (test: input resets all keys on blur).
2. Tab hidden / huge frame dt spike → accumulator clamps (max 8 sub-steps) instead of spiral-of-death (test in `loop.test.ts`).
3. Generated room with unreachable spawn or exit → generator rejects & retries (test in `generator.test.ts`).
4. Card pool exhaustion (all cards owned) → offer falls back to heal/lumen cards, never empty (test in `cards.test.ts`).
5. Ragdoll/debris budget overflow during chain explosions → oldest recycled, count never exceeds cap (test in `budget.test.ts`).

- [ ] Tests first: loop clamps sub-steps at 8 for a 5 s dt; alpha in [0,1); rng determinism + fork independence; slowmo returns to 1 after duration; hitstop zeroes sim dt; budget evicts oldest, size ≤ cap.
